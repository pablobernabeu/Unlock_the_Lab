# Version 1 backups (frozen)

These files are the last daily backups taken by the version 1 workflow, which committed to this folder until version 2 was released. They are kept so that the history of the data stays in one place and are no longer updated.

Current backups are on the [`data` branch](https://github.com/pablobernabeu/Unlock_the_Lab/tree/data), taken by `.github/workflows/backup.yml`. [`docs/data.md`](../docs/data.md) describes the data, including how version 1 records differ, and [`docs/deployment.md`](../docs/deployment.md#backups-and-restoring) explains how to restore them.
